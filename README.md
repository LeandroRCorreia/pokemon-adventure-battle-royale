# Cobblemon Battle Royale

Datapack de Battle Royale para o modpack COBBLEVERSE 1.7.42, Minecraft 1.21.1 e Fabric Loader 0.18.4.

O codigo mantido neste repositorio fica em:

```text
COBBLEVERSE - Pokemon Adventure [Cobblemon]/saves/BattleRoyale/datapacks/cobblemon_br_datapack
```

Os mods e demais dependencias de terceiros nao sao versionados. A lista original do modpack esta em `manifest.json` e `modlist.html`.

## Uso

Instale o modpack COBBLEVERSE compativel, copie `cobblemon_br_datapack` para `saves/<mundo>/datapacks/` e execute no Minecraft:

```mcfunction
/reload
/function br:start
```

Para encerrar uma partida:

```mcfunction
/function br:stop
```
